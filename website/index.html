QUERY EXAMPLE

Query financial statements

  1. Download and decompress a database release.
  2. Open the SQLite file in your preferred client.
  3. Query by CIK, period, and reporting currency.

Financial values are stored as decimal text. Cast explicitly when performing numeric calculations. Q1–Q4 and FY identify periods; frequency distinguishes annual and quarter rows.

Apple · annual revenue 
SELECT date, fiscalYear, revenue,
       reportedCurrency
FROM income_statements
WHERE cik = '0000320193'
  AND period = 'FY'
  AND reportedCurrency = 'USD'
ORDER BY date DESC
LIMIT 5;

Before you use the data

Mappings are provisional and normalization may include candidate selection, calculations, and sign adjustments. Validation does not establish accounting correctness. Historical coverage is uneven. Check material values against the original filings.
